# Tyrell Love

A custom Visual Studio Code extension that applies a dark cybernetic moonlit wallpaper and pairs it with a custom retro file icon theme.

## Features

* **Custom Workbench Wallpaper:** Applies a dark greenish/bluish/blackish atmospheric background behind your editor and sidebar.
* **Tyrell Love Retro Icons:** Replaces default folder and file icons (`.ts`, `.js`, `.json`, `.html`, `.css`) with custom retro artwork.

## Usage

### 1. Apply the Wallpaper
1. Open the Command Palette (`Ctrl + Shift + P` on Windows/Linux, `Cmd + Shift + P` on macOS).
2. Run **`Tyrell Love: Apply Wallpaper`**.
3. Fully close and reopen VS Code for the background to take effect.

> **Note:** Because applying a background wallpaper modifies VS Code's internal workbench stylesheet, VS Code may display a `[Unsupported]` / *"Your Code installation appears to be corrupt"* notification on startup. You can safely dismiss this warning by selecting **Don't Show Again**.

### 2. Activate the Retro File Icons
1. Open the Command Palette (`Ctrl + Shift + P`).
2. Run **`Preferences: File Icon Theme`**.
3. Select **`Tyrell Love Retro Icons`**.
